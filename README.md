Port ARMSX2 to R36S on ARKOS2.0

ARMSX2 successfully port to ARKOS2.0 with GPU malisx2 custom driver acceleration, fps went from 8 fps to 45 fps, most of the titles tested have nearly full speed.
For some reason the display doesn’t working, there is only sound output.

Work on older ARKOS firmware, and run on portmaster for dummy proof and seamless setup, just unpack everything into port directory and run it.

Run a lot better than on lineageOS or android, battery life is more stable and less random system shut down or frozen. Lower memory footprint and more responsive.
